# ASTRA

Ứng dụng quản lý nhiệm vụ cá nhân kết hợp RPG nhẹ: làm nhiệm vụ để nhận EXP, Gold và củ cải ngâm, lên level, mua khung và avatar, đổi phần thưởng.

## Có gì trong bản này

- Trang chủ, Nhiệm vụ (lặp lại, checklist, deadline có giờ), Nhân vật, Cửa hàng, Thành tựu, Cài đặt
- Điểm danh mỗi ngày, củ cải ngâm, khung avatar và avatar Usagi
- Học cùng: Pomodoro, đếm ngược, bấm giờ, âm thanh nền, nhạc YouTube

## Chạy

Mở file `index.html` bằng trình duyệt, hoặc bật GitHub Pages cho repo này.

## Lưu ý

- Dữ liệu lưu trong trình duyệt của từng thiết bị, chưa đồng bộ giữa các máy.
- Sao lưu hoặc chuyển dữ liệu: Cài đặt, Xuất dữ liệu, rồi Nhập dữ liệu ở nơi mới.
- Đồng bộ nhiều thiết bị (Supabase) chưa được làm.
